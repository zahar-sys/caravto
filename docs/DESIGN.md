# Ровный ход — автосервис

Уточнение владельца от 12.11.2026 заменяет мебель автосервисом. Цель: выбрать работы, узнать предварительную стоимость труда, отправить заявку и увидеть согласованное время и цену. Запчасти оцениваются отдельно; выбор услуги не меняет геометрию автомобиля. Игру не включаем по умолчанию: механика чистки мебели не соответствует ремонту; настройки бонуса и отключение сохранены.

## Выбранное решение
Next.js 15, React 18, Three.js / прямое управление сценой в React. Серверные обработчики Node. Локально SQLite с постоянной записью; для serverless обязательна PostgreSQL через Supabase REST, RLS закрывает данные от клиента. Раздельные экземпляры и базы. Все секреты на сервере. В production нет fallback на SQLite.

Альтернативы: статический каталог не завершает обработку заявки; собственный PostgreSQL сервер требует инфраструктуры. Выбран адаптер Supabase PostgreSQL с переносимой SQL схемой и локальным автономным режимом.

## Расчёт
Для каждой известной позиции: базовый тариф варианта × количество × (1 + процент сложности). Округление каждой строки до целого рубля half-up. Потом сумма строк; минимум относится только к труду. Выезд добавляется отдельно при наличии соответствующей услуги. «Другое» — ручная оценка, никогда ноль. Смешанный заказ показывает известную часть + ручную оценку. В заявке сохраняется полная копия тарифов и результата. Сервер принимает только состав, заново валидирует и считает его.

## Дизайн
Светлый ледяной #F5F6F8, белый #FFFFFF, чернильный #20232C, серый #7A7F89, кобальт #315EED, зелёный #34765B. Тёмная тема: #15171D / #20232C. Системный sans с выразительным плотным крупным заголовком. Один центральный 3D-автомобиль на тихом подиуме, слева объяснение, справа компактная калькуляция. Широкие поля, тонкие разделители, скругления 14–24, кнопки от 44px. На телефоне последовательные блоки без перекрытий.

## Ассеты и ограничения среды
Исходная геометрия автомобиля создаётся программно и передаётся с генератором, GLB и SVG постером под CC0. Источники сторонних свободных моделей проверяются отдельно; платных моделей и внешней загрузки на каждый визит нет. Figma не подключена, Blender/bpy не обнаружены. Отдельный редактируемый SVG-макет и исходники компонентов заменяют недоступный Figma-файл, но не называются файлом Figma. Не выдавать SVG за .blend.

## Данные и доступ
Непредсказуемый 256-битный токен заявки. Фото после проверки сигнатуры и декодирования sharp хранятся отдельными приватными записями, не возвращаются клиентским API. Идемпотентность: уникальный ключ записи, повтор получает прежнюю заявку. Сессии владельца серверные; пароль scrypt, смена отзывает сессии. Origin, лимиты частоты и размера, серверная валидация, запрет кеширования приватных маршрутов. История клиента исключает приватные заметки.
