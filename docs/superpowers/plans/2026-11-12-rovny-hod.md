# Ровный ход Implementation Plan

**Goal:** Законченный путь заявки в автосервис с кабинетoм.
**Architecture:** Next.js с общим модулем расчёта и валидации, репозиторием SQLite / Supabase PostgreSQL, приватными фото и сессиями.
**Tech Stack:** TypeScript, React 18, Next 15, R3F, Drei, Three, sharp.
**Spec:** docs/DESIGN.md

## Global Constraints
Русский интерфейс; минимум только к работе; ручная оценка не ноль; сервер пересчитывает; постоянная запись до успеха; никакой онлайн оплаты. Пользователь разрешил самостоятельно выбрать решение и выполнить обратимые действия.

## Review Focus
- Повтор запроса после потери ответа возвращает прежнюю заявку.
- Невалидный формат фото и отсутствие фото для ручной оценки отклоняются.
- Чужие сессии, угадываемый номер, приватные заметки не раскрывают заявку.
- Клиентский черновик сохраняется после ошибки и перезагрузки.
- WebGL недоступен: постер и форма остаются рабочими.

## Tasks
- [ ] 1. Тесты расчёта, объединения, валидации; модуль domain.ts. Проверить RED, затем GREEN.
- [ ] 2. Репозиторий постоянных записей, SQL миграция PostgreSQL, авторизация, origin/rates, заявки, фото и кабинет. Интеграционные проверки реальными HTTP запросами.
- [ ] 3. Авторская 3D геометрия, GLB, постер, сцена с ограничениями камеры и fallback.
- [ ] 4. Каталог, корзина, форма с черновиком, приватный статус и кабинет, две темы, адаптивность.
- [ ] 5. Метаданные, PWA, политика, редактируемые макеты, лицензии и инструкция.
- [ ] 6. Типы, тесты, production build, браузер desktop/mobile и вся цепочка. Зафиксировать реальные ограничения.
