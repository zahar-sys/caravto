# Лицензии

Оригинальная модель Rovny Touring, исходная геометрия, генератор, SVG-постер и иконки приложения: CC0-1.0, https://creativecommons.org/publicdomain/zero/1.0/ . Можно коммерчески использовать, изменять и передавать с исходниками. Это оригинальная геометрия без бренда реального автомобиля.

Исследованный внешний источник для первоначальной мебельной темы: Kenney Furniture Kit — https://kenney.nl/assets/furniture-kit, CC0. В приложение после смены темы не включён.

React / React DOM, Next.js, Three.js, Zod — MIT. Lucide React — ISC. Sharp — Apache-2.0. Лицензии транзитивных зависимостей находятся в соответствующих пакетах node_modules при установке. React Three Fiber и Drei не используются в итоговой сборке: несовместимый React-рендерер заменён прямой сценой Three.js в React.

Исходный код самого приложения предоставлен по MIT (LICENSE), за исключением отдельно перечисленных ассетов CC0 и сторонних зависимостей.
